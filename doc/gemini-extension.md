# Gemini 网页保存扩展

本扩展用于在 `personal` 本地模式下，把 Gemini 网页生成的图片、提示词和可读取的参考图保存到 Banana Gallery 的作品库或配方库。若当前使用 `personal-remote`，扩展仍只允许通过本机监听端口导入，不会开放远程 Tunnel 入口。

## 安装

Windows 分发包用户先通过根目录 `gallery.cmd` 启动，加载扩展的目录是 `app\extension\gemini-to-banana`，API 地址仍为 `http://localhost:3333`。安装与升级流程见 [`windows-local.md`](windows-local.md)。下面的 `gallery.sh` 是 Mac 自用入口。

1. 启动 Banana Gallery：

```bash
./gallery.sh start
```

2. 在 Chrome / Edge 打开扩展管理页。
3. 启用「开发者模式」。
4. 选择「加载已解压的扩展程序」，目录选：

```text
extension/gemini-to-banana
```

扩展默认连接：

```text
http://localhost:3333
```

如需修改，打开扩展详情页的「扩展选项」，填写 Banana Gallery API 地址。

使用 `personal-remote` 时这里仍应保持 `http://localhost:3333`，不要填写
`https://gallery.example.com`。本机监听端口会使用 personal session；远程监听端口即使通过
Cloudflare Access 登录，也会拒绝第一版扩展导入接口。

## 使用

1. 打开 `https://gemini.google.com/`。
2. 生成图片。
3. 点击页面右下角的「保存到 Banana」悬浮按钮。
4. 在确认面板中检查生成图、参考图、提示词、作品/配方类型、标签和参考图状态。
5. 点击「确认保存」。

确认面板默认保存为「配方」，也可以手动切换为「作品」。只要结果图和提示词可用，即使部分参考图读取失败，也可以保存；已读取到的参考图会随条目一起上传。保存成功后，条目会写入 Banana Gallery，并带有 `gemini-web` 标签和 `sourceFile = gemini-web`。

已打开的画廊会自动显示新保存的条目，无需点击「加载更新」：回到画廊窗口时立即检查，持续在前台时每 10 秒检查一次。当前作品/配方分区、搜索和筛选条件仍然生效；若新条目不符合当前条件，可切到对应分区的全部图片查看。已有条目的外部修改或删除仍通过「加载更新」应用，保留正在查看或编辑的内容。

扩展 0.3.14 补齐了真实 Gemini 页面中的提示词重复修复：排除正文内部供屏幕阅读器使用的隐藏摘要（`screen-reader-user-query-label`）。0.3.13 只处理了并列的预览/正文副本，未覆盖这个结构。提取仍以当前用户消息为边界；折叠状态也会读取页面中已有的完整正文。不会删除普通正文里有意重复的句子或段落，也不会改写确认面板中手动编辑的提示词。

如果以前保存的重复提示词已被复制回 Gemini 并发送，重复内容就已成为该轮实际正文。扩展更新会阻止继续叠加隐藏摘要，但这类旧内容仍需在配方或保存确认面板中清理；仅重新加载扩展不会改写历史消息。

更新仓库中的扩展后，在 Chrome / Edge 的扩展管理页找到「Gemini to Banana Gallery」，点击「重新加载」，再刷新已打开的 Gemini 页面。仅刷新 Gemini 页面不会让已加载的扩展自动更新。

提示词按 Gemini 页面里的段落和 `<br>` 结构还原：普通换行只保存一个换行，原提示词中的空行仍会保留，不会把页面布局产生的段落间距误存成额外空行。

## 参考图读取策略

扩展优先使用当前上传、粘贴或拖拽到 Gemini 的原始参考图缓存。多张图片即使逐张选择、粘贴或拖入，也会按顺序累计缓存，不会用后一张覆盖前一张。对于旧会话，扩展会尝试从当前页面可见附件恢复参考图。

旧会话恢复不要求附件原图尺寸较小：Gemini 页面里显示为缩略图的高分辨率上传图也会被识别。若缩略图来自 Google 图片 CDN，扩展后台会代为读取图片并转换成可上传文件。

如果扩展无法确认「页面显示的参考图数量」和「可保存的参考图数量」一致，确认面板会显示参考图不完整或读取失败的提示，但不会阻止保存结果图和提示词。需要完整参考图时，请重新上传参考图并重新生成，再保存新结果。

## 范围限制

- 第一版只支持 Chromium 系浏览器。
- 第一版只支持 Banana Gallery `personal` 本地入口；`personal-remote` 配置下也必须连接本机端口。
- 第一版不发布到 Chrome Web Store。
- Gemini 网页 DOM 可能变化；若按钮不出现或参考图识别失败，需要更新扩展选择器。

### 来源与后续整理

主应用会保存扩展已有负载中的 `sourceUrl` 与 `capturedAt`，只接受不带用户名/密码的 HTTP(S) URL 和有效时间；不会自动打开或抓取来源页面。旧扩展不发送来源时仍可导入，详情显示“未记录”。导入后可在待整理视图命名、加内容标签、归组、比较与导出；来源标签不算内容分类。

## 0.4.0 重复检测与重试

相同采集请求沿用固定 requestId，网络失败后重试返回原条目，避免重复写入。服务端根据图像哈希或提示词＋来源＋有序参考图哈希提示候选；用户选择跳过或仍然保留新条目。提交后的输入固定，要修改请关闭面板重新采集。此能力需主应用 0.21.0；旧扩展负载仍可导入。更新文件后在扩展管理页重新加载扩展，并刷新 Gemini 网页。详细范围见 [个人设置与整理](personal-settings.md)。
